# 车机版 UI 改造 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让同一个 APK 在车机横屏上以"大触控目标、左右分栏、字号下限 1.15"的形态呈现，手机端保持逐像素不变。

**Architecture:** 引入全树唯一的形态判定 `UiSurface`（CompositionLocal），把 `Dimens` 中 9 个尺寸 token 改成按形态取值的 `@Composable get()`（127 个调用点零改动），再在 4 个宿主/列表页按 `isCarSurface()` 分支换成 NavigationRail + Adaptive 网格，播放页改左右分栏，迷你条抬高命中区并接上已存在但从未被 UI 调用的 ±15 秒方法。

**Tech Stack:** Kotlin 2.1 · Compose BOM 2024.12.01 · Material3 1.3.x · Media3 1.5.1 · Hilt · DataStore Preferences

**Spec:** `doc/specs/2026-09-26-car-ui-design.md`（执行前必读，本计划按它论证）

## Global Constraints

- 目标机：梁山嘟嘟 S1，10 寸屏、物理分辨率 1280x720，SoC 为展锐 UIS7862/7865 同系（不影响 UI 结论）；**上报 density 未知，160（→1280x720dp）与 240（→853x480dp）两档必须都实测**
- 不新增依赖，不改 `build.gradle.kts` / `gradle/libs.versions.toml`
- **本项目无测试源码集**（只有 `app/src/main`），不新增 JUnit/Espresso 基建（既有独立决策，需另行批准）。每个任务的"测试"= 编译通过 + 模拟器上 `tools/car_assert.ps1` 的 bounds 断言 + 截图目视
- `minSdk 26 / targetSdk 35` 不动；`AndroidManifest.xml` 只允许新增 BootReceiver 注册
- 手机端零回退：`UiSurface.Phone` 下 token 取值与布局分支必须与本计划开始前（commit `3d5dc7a`）逐像素一致
- 新代码禁止裸 `dp` 字面量，一律引用 `Dimens.*`；圆角用 `MaterialTheme.shapes.*`；颜色用 MaterialTheme 语义角色
- 每个 `onClick` / `onValueChange` 必须被真实调用，禁止空 lambda
- 车机档可点控件命中区 ≥ `Dimens.TouchMin`(88dp)；**不移除任何既有交互控件**
- 中文文案面向中老年用户：语气直白、不用英文占位、不出现内部 key
- 版本号的坑：`versionCode/versionName` 由 `git rev-list --count HEAD` 推导，**每提交一次 APK 文件名就变**。安装一律用：
  ```powershell
  $adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
  .\gradlew.bat assembleDebug --console=plain -q
  $apk = (Get-ChildItem app\build\outputs\apk\debug\*.apk | Select-Object -First 1).FullName
  & $adb install -r $apk
  ```
- 设备就绪前置：任何 adb 命令前先 `& $adb wait-for-device`；`wm size/density` 改完要 `adb shell settings put system user_rotation 1`（并先 `accelerometer_rotation 0`）才稳定横屏

## Review Focus

spec 隐含但单个任务的断言不覆盖、最容易在真车上咬人的 5 条：

1. **density 上报 240 的 1280x720 车机**（→ 853x480dp，`sw=480`）会被自动判定成手机档 → 期望：设置里手动切「车机」后布局正常、88dp 目标在 480dp 高里不裁切（Task 2 判定 + Task 9 density=240 实测）
2. **车机档 + 用户选「超大」**（factor 1.3 与 88dp 行高叠加）→ 期望：行高随内容增长、文字只省略号不溢出遮挡（Task 9 用超大档复跑全页）
3. **车机档横屏 720dp 高时播放页首屏**必须含播放/暂停、上一个、下一个、收藏、睡眠定时器，不需滚动（Task 5 断言）
4. **形态来回切换（旋转 / 手动改模式 / 分屏）**不崩溃、不丢播放状态、迷你条不残留旧高度（Task 9 切换压测）
5. **±15 秒按钮在 `duration == 0`（未知长度/直播）时**必须无副作用而不是跳到 0（Task 6 断言 + 复用 PlayerManager 既有 `coerce` 语义）

New-Item -ItemType Directory -Force -Path $out | Out-Null

  foreach ($c in $nodes) {

- [ ] **Step 1: 写 `UiSurface.kt`**

```kotlin
package com.radio.chinese.ui.theme

import android.content.res.Configuration
import androidx.compose.runtime.Composable
import androidx.compose.runtime.compositionLocalOf
import androidx.compose.runtime.getValue
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.platform.LocalConfiguration

/** 界面形态。全树唯一判定源，页面只允许用 isCarSurface() 分支。 */
enum class UiSurface { Phone, Car }

val LocalUiSurface = compositionLocalOf { UiSurface.Phone }

/**
 * 纯函数判定，便于静态核对。
 * mode：0=自动 / 1=强制手机 / 2=强制车机。
 * 加装车机的 density 极随意（1280x720 可能报 160 也可能报 240），
 * 所以自动判定必须能被手动覆盖，否则部分车机永远进不了车机档。
 */
fun resolveUiSurface(mode: Int, smallestWidthDp: Int, landscape: Boolean): UiSurface = when (mode) {
    1 -> UiSurface.Phone
    2 -> UiSurface.Car
    else -> if (smallestWidthDp >= 600 && landscape) UiSurface.Car else UiSurface.Phone
}

@Composable
fun rememberUiSurface(mode: Int): UiSurface {
    val cfg = LocalConfiguration.current
    // 读 LocalConfiguration 本身就会随旋转/分屏重组，无需额外 key
    return remember(cfg.smallestScreenWidthDp, cfg.orientation, mode) {
        resolveUiSurface(
            mode,
            cfg.smallestScreenWidthDp,
            cfg.orientation == Configuration.ORIENTATION_LANDSCAPE
        )
    }
}

@Composable
fun isCarSurface(): Boolean = LocalUiSurface.current == UiSurface.Car
```

```kotlin
@Composable
fun ChineseRadioTheme(
    themeMode: Int = 0, // 0 = system, 1 = light, 2 = dark
    fontScale: Float = 1f,
    uiMode: Int = 0,    // 0 = 自动, 1 = 手机, 2 = 车机
    content: @Composable () -> Unit
) {
    val surface = rememberUiSurface(uiMode)
    // 车机档取字号"下限"而不是叠乘：标准档在车机上按「大」渲染，
    // 用户仍可选超大(1.3)，不会出现 1.3×1.15 的失控放大。
    val effectiveScale = if (surface == UiSurface.Car) maxOf(fontScale, 1.15f) else fontScale
    val darkTheme = when (themeMode) {
        1 -> false
        2 -> true
        else -> isSystemInDarkTheme()
    }
    val colorScheme = if (darkTheme) DarkColorScheme else LightColorScheme

    CompositionLocalProvider(LocalUiSurface provides surface) {
        MaterialTheme(
            colorScheme = colorScheme,
            typography = appTypography(effectiveScale),
            shapes = AppShapes,
            content = content
        )
    }
}
```

```kotlin
package com.radio.chinese.ui.theme

import androidx.compose.runtime.Composable
import androidx.compose.ui.unit.Dp
import androidx.compose.ui.unit.dp

/**
 * 全站尺寸 token，按 UiSurface 换档。
 *
 * 这些属性是 @Composable get()：调用点写法不变（Dimens.TouchMin），
 * 但只能在 composable 上下文取值——全项目 127 处调用已核实全部满足。
 * 手机档取值必须与换档前完全一致，这是"手机端零回退"的落点。
 */
object Dimens {
    private val car: Boolean
        @Composable get() = LocalUiSurface.current == UiSurface.Car

    // 间距节奏（4 的倍数，两档共用）
    val GapTiny: Dp = 4.dp
    val GapSmall: Dp = 8.dp
    val GapMedium: Dp = 12.dp
    val GapLarge: Dp = 16.dp
    val GapXLarge: Dp = 24.dp
    val GapHuge: Dp = 32.dp

    // 布局
    val ScreenPadding: Dp @Composable get() = if (car) 32.dp else 16.dp
    val ListGap: Dp @Composable get() = if (car) 16.dp else 8.dp
    val CardPadding: Dp = 12.dp
    val RowVerticalPadding: Dp = 12.dp
    val ChipGap: Dp = 8.dp

    // 高度与命中区
    val RowMinHeight: Dp @Composable get() = if (car) 88.dp else 56.dp
    val TouchMin: Dp @Composable get() = if (car) 88.dp else 48.dp
    val IconSmall: Dp = 18.dp
    val IconMedium: Dp = 24.dp
    val IconLarge: Dp = 32.dp
    val MiniPlayerHeight: Dp @Composable get() = if (car) 104.dp else 72.dp
    val OperaMiniPlayerHeight: Dp @Composable get() = if (car) 144.dp else 104.dp
    val MiniPlayerProgress: Dp = 2.dp

    // 封面/图标位
    val CoverTiny: Dp = 40.dp
    val CoverSmall: Dp @Composable get() = if (car) 72.dp else 48.dp
    val CoverLargeMax: Dp @Composable get() = if (car) 320.dp else 220.dp

    // 局部滚动上限
    val SourceListMax: Dp @Composable get() = if (car) 280.dp else 160.dp

    // 播放主控件（替换原先写死的 GapHuge*2 与 40.dp）
    val PlayButtonSize: Dp @Composable get() = if (car) 96.dp else 64.dp
    val PlayIconSize: Dp @Composable get() = if (car) 56.dp else 40.dp
}
```

/** 一个页签：文案 + 图标。图标只在车机档 rail 上显示，手机档沿用纯文字 Tab。 */
data class SurfaceTab(val label: String, val icon: ImageVector)

/**
 * 页签栏双形态：手机档是顶部 TabRow，车机档是左侧 NavigationRail。
 * 关键约束：这不是"把 Tab 删掉"，同一批页签、同一个 currentPage/onSelect，
 * HorizontalPager 的左右滑动照常可用——能力不减，只是换个更适合横屏的摆放。
 */
@Composable
fun SurfaceTabBar(
    tabs: List<SurfaceTab>,
    currentPage: Int,
    onSelect: (Int) -> Unit,
    modifier: Modifier = Modifier
) {
    if (isCarSurface()) {
        NavigationRail(modifier = modifier.fillMaxHeight()) {
            tabs.forEachIndexed { index, tab ->
                NavigationRailItem(
                    selected = currentPage == index,
                    onClick = { onSelect(index) },
                    icon = { Icon(tab.icon, contentDescription = null, modifier = Modifier.width(Dimens.IconLarge)) },
                    label = { Text(tab.label, style = MaterialTheme.typography.titleSmall) },
                    modifier = Modifier.heightIn(min = Dimens.TouchMin)
                )
            }
        }
    } else {
        TabRow(selectedTabIndex = currentPage, modifier = modifier) {
            tabs.forEachIndexed { index, tab ->
                Tab(
                    selected = currentPage == index,
                    onClick = { onSelect(index) },
                    text = { Text(tab.label) }
                )
            }
        }
    }
}

```kotlin
    /**
     * 开机自启是用 startForegroundService 拉起来的，必须在 5 秒内 startForeground，
     * 否则系统抛 "did not then call Service.startForeground"。
     * 这里只挂一条"已就绪"通知、不播放，避免一上车就突然出声。
     */
    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        startForeground(NOTIFICATION_ID, buildReadyNotification())
        return super.onStartCommand(intent, flags, startId)
    }

    private fun buildReadyNotification(): Notification {
        val openIntent = packageManager.getLaunchIntentForPackage(packageName)?.let {
            PendingIntent.getActivity(this, 0, it, PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT)
        }
        return NotificationCompat.Builder(this, RadioApp.NOTIFICATION_CHANNEL_ID)
            .setSmallIcon(android.R.drawable.stat_sys_headset)
            .setContentTitle(getString(R.string.app_name))
            .setContentText("已就绪，点按打开继续收听")
            .setContentIntent(openIntent)
            .setOngoing(true)
            .setOnlyAlertOnce(true)
            .setCategory(NotificationCompat.CATEGORY_TRANSPORT)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build()
    }

    companion object {
        /** 1002 避开 Media3 自己用的 1001 */
        private const val NOTIFICATION_ID = 1002
    }
```

- [ ] **Step 3: BootReceiver**

```kotlin
package com.radio.chinese.service

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import androidx.core.content.ContextCompat
import com.radio.chinese.data.local.RadioPreferences
import dagger.hilt.android.AndroidEntryPoint
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.runBlocking
import javax.inject.Inject

/**
 * 开机后恢复播放会话，不自动播放。
 * 部分车机 ROM 的省电策略会拒绝后台启动前台服务：静默失败即可，
 * 用户上车手动打开 App 的代价远小于开机弹一个错误。
 */
@AndroidEntryPoint
class BootReceiver : BroadcastReceiver() {

    @Inject lateinit var preferences: RadioPreferences

    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action != Intent.ACTION_BOOT_COMPLETED) return
        val pending = goAsync()
        runBlocking {
            try {
                if (preferences.bootAutoStart.first()) {
                    ContextCompat.startForegroundService(
                        context, Intent(context, RadioService::class.java)
                    )
                }
            } catch (_: Exception) {
                // 见类注释：拒绝就放弃，不打扰用户
            } finally {
                pending.finish()
            }
        }
    }
}
```
